# Android 项目目标（Goal）

## 项目背景

minibox Android 是 Go 后端的用户界面和设备代理。

## 总目标

提供稳定、可访问、默认安全的会话与设备体验，不在前端复制后端业务内核。

## 成功标准

- REST/SSE/WS 在断网、重连和错误场景下状态清楚且不重复数据。
- 用户可完成连接、会话和设备能力管理。
- TalkBack、字体放大、深色和不同窗口尺寸可用。
- 设备危险动作在认证、权限、审批不完整时拒绝。

## 范围边界（做 / 不做）

- 做：UI、网络、状态、凭据安全存储、设备执行器。
- 不做：本地 Agent/LLM、后端 SQLite 直连、无契约占位按钮。

## 约束条件

- Kotlin/Compose/Navigation 3。
- 后端协议为唯一业务事实源。
- 真机副作用逐项授权验收。
