# Android 实施计划（Plan）

## 里程碑

1. 决策与契约冻结。
2. Gradle/Compose/Navigation 3 工程。
3. REST/SSE/WS 网络地基。
4. 会话主流程。
5. 知识与管理。
6. 设备代理与真机分项验收。

## 任务拆解

- F0：模型、网络、连接诊断。
- F1：会话、SSE reducer、错误状态。
- F2：知识库与管理 DTO。
- F3：设备前台服务、RPC 和执行器。

## 验收节点

- Mock fixture 通过后才连接稳定后端。
- 模拟设备通过后才申请真机副作用授权。
- 每个屏幕通过语义、字体、深色和窄屏检查。

## 风险与回滚

- 风险：后端认证/审批/持久化契约未完全冻结。
- 回滚：阶段独立提交；首版隐藏高风险未完成入口；DTO 保持兼容。
